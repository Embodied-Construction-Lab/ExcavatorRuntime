# orin

- conda环境
  - excavator-orin
- 系统环境
  - 不需要额外source
- 执行命令

```shell
python orin_state_sender.py \
  --serial-port /dev/ttyTHS1 \
  --control-enabled \
  --pc-host 192.168.0.220 \
  --edge-config deploy/edge_runtime.remote.json \
  --edge-motion-authorization ALLOW_EDGE_MACHINE_MOTION \
  --print-every 100 \
  2>&1 | tee "deploy/logs/rl_follow_${run_tag}_stdout.log"
  
参数:  
  serial-port ,STM32 port 
  control-enabled ,开启控制
  pc-host ,pc局域网ip地址
  edge-config , 各项配置文件地址
  edge-motion-authorization ,令牌,当允许控制挖掘机时必须传入ALLOW_EDGE_MACHINE_MOTION
  print-every ,打印间隔
```

# PC

- conda环境
  - 需退出conda环境
  - conda deactivate
- 系统环境
  - 需要激活ros2环境以及项目编译目录
  - source /opt/ros/jazzy/setup.zsh
  - source ros2_ws/install/setup.zsh
- 执行命令

```shell
# 可视化rviz
ros2 launch airy_excavator_bringup operator.launch.py \
  profile:=live_commissioning \
  motion_authorization:=ALLOW_LIVE_MACHINE_MOTION \
  orin_host:=192.168.0.55 \
  orin_port:=18083
  
参数:
  profile ,控制策略,如需控制真机执行需要传入live_commissioning
  orin_host , orin局域网ip
  orin_port , orin开发端口

# 演示脚本
ros2 run airy_mission_runtime run_excavation_demo \
  --program /home/zhaoshuai/workspace_uinty/RL_prj/AiryLidar/mission/config/excavation_demo.json \
  --repeat 1

参数:
  program , 演示脚本
  repeat , 重复次数
```
