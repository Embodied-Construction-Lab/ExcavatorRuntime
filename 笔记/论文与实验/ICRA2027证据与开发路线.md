# ICRA 2027 证据与开发路线

更新日期：2026-08-27

这篇笔记把论文中的结果占位、现有工程证据和下一步开发一一对应。论文中的数字只能来自冻结后的正式 Experiment Run；当前训练、V3-A 演示和历史日志只能作为工程可行性证据，不能直接填成论文结果。

## 1. 固定论文路线与四项贡献

当前论文路线固定为：

`TADPS 选点 → waypoint planning → TC-BTF MoveToDig → ACT/VDL Dig-and-lift → TC-BTF CarryMaterial → Fixed Dump → 重新感知`

四项技术贡献必须保持独立：

1. **Regime-factorized architecture**：将自由空间轨迹跟踪与土体交互技能分解，并用唯一运动权限与事件驱动切换组织重复闭环。
2. **TADPS**：从 LiDAR elevation map 生成 terrain-valid、temporally stable 的三维挖掘目标。
3. **TC-BTF**：使用同一 task-conditioned policy 跟踪 MoveToDig 和 CarryMaterial 的 multi-waypoint 轨迹，并验证 sim-to-real 迁移。
4. **VDL Policy**：使用真实遥操示教训练 ACT Dig-and-lift，以固定前视 RGB + 11D proprioception 输入，输出 `[boom, stick, bucket, swing]` 四维归一化动作。

Fixed Dump 是确定性倾倒行为，不属于模仿学习。已废止的 residual-conditioned ACT 不得恢复。试验体系用来验证上述四项贡献，不作为第五项贡献。

- `dig_only` front-only 数据：104 个有效 source Episode；训练/验证为 83/21，训练/验证帧为 10,436/2,571。
- `dig_transport_dump` 双 RGB 数据：35 个唯一 source Episode；训练/验证为 28/7，训练/验证帧为 5,737/1,424。
- `dig_only` swing-zero ACT 正在以 seed 2027、400,000 steps 训练；脚本随后训练 300,000-step 双 RGB `dig_transport_dump` 模型并执行 checkpoint 评价。
- Experiment Run、Evaluation Harness、V3-A 阶段事件、handoff 分析器和安全归零证据接口已经存在。

### 需要审计或正式验证

- 当前采集时 block/zone 没有严格维护，104 条数据适合训练和工程验证，但不能作为独立土壤 block 的统计样本。

- 当前 handoff 和多铲日志只是工程观察；R12 需要冻结配置后的重复 HIL/真机采样。
- 当前 `hybrid_evidence` scope 仍有历史 `training_internal` 配置与旧 checkpoint 引用；正式实验必须换成新 checkpoint/hash 和 `held_out_experiment`。

## 4. 必须开发的最小集合

### P0：训练结束后立即做

1. **冻结 ACT 终止口径**
   - 当前冻结工程基线统一使用 125-step horizon。正式论文实验的终止契约需在 pilot 后另行冻结；在此之前不得把未实现的“外部几何判据”写成已有能力。
   - 理由：它对 RGB/state-only 是公平、简单、可复现的 matched budget；现在临时开发几何判据会引入新的阈值和故障源。
2. **R01 数据证据生成器**
   - 从 raw、quality report、conversion 和 split provenance 生成唯一 JSON/CSV/Markdown summary。
   - 对 source 重复、失败 Episode、frame/sequence 数、时长、相机角色和 hash fail-closed。
3. **state-only ACT 对照**
   - 训练和推理都将图像替换为同一常量 tensor，视觉编码器和参数量保持不变。
   - 把 observation variant 写进 config、deployment manifest、checkpoint evaluator 和 Experiment Run。
4. **正式试验记录界面**
   - 每次 attempted scoop 绑定 run/block/method/scoop index。
   - 录入 payload mass、spillage、completion、timeout、intervention、failure taxonomy 和备注。
   - 不自动删除失败；称重原始记录和视频/日志作为 artifact。

### P1：形成论文核心结果

1. **TADPS 最小迁移**
   - 从 `excavator_perception` 只迁移算法思想和必要公式，不迁移 build artifact。
   - 在 AiryLidar 建立纯输入→输出 selector、严格配置和 replay 测试。
2. **TADPS 对照/消融 Harness**
   - 同一 elevation map sequence 运行 TADPS、highest point、reachability-filtered highest point。
   - 统计 jitter、switch count、valid/dropout、runtime、planner acceptance 和下游 payload。
3. **正式 block 实验 runner**
   - 保存初始 pile map；方法顺序随机或平衡；固定 attempted scoop 数；失败也占 denominator。
   - 当前训练数据绝不兼作 held-out 物理评价 block。
4. **R11/R12 正式证据配置**
   - 新建 `held_out_experiment` 配置，绑定最终 checkpoint、RL ONNX、轨迹、机器 profile 和三仓 commit。
   - 用现有 Resident/Handoff Module 采集，不重写一套 Runtime。

### P2：只有主证据闭合后再做

- 把完整 `dig_transport_dump` ACT 作为“更拟人端到端技能”的后续/补充实验，不替换当前论文主路线。
- 只有决定保留“TC-BTF 优于传统控制器”这一强主张时，才继续开发可信 IK/模型控制基线；简单 P controller 不足以做公平论文对照。
- Diffusion Policy、自动挖点在线部署和更多硬件扩展放在核心 R01/R02/R04–R12 闭合之后。

## 5. 正式物理实验的共同协议

每个 digging method 使用相同的目标调度、RL checkpoint、Fixed Dump、超时和安全边界。一个 block 只运行一种 digging method 的连续 attempted scoops：

```text
重建局部料堆并保存初始 map
→ 随机/平衡分配方法
→ 执行固定数量 attempted scoops
→ 每铲称重并记录成功/失败/接管
→ 保存每铲前后的 pile observation
→ 整个 block 不更新模型或阈值
```

统计单位优先是独立 pile block，不是帧数，也不能把同一个持续演化料堆上的相邻铲当作独立样本。正式 block 数应在小规模 pilot 后根据方差和目标置信区间确定，不能现在凭感觉写死。

## 6. 今日可并行完成的工作

训练 GPU 正忙时，优先做不抢 GPU 的工作：

1. 冻结论文主张和 ACT 终止口径。
2. 完成 R01 audit 设计及重复 source 审计。
3. 设计 state-only 配置/manifest 契约和测试，不启动第二个训练进程。
4. 设计称重、block、failure taxonomy 的 UI/Run schema。
5. 把旧 TADPS 的输入、评分项、滞回和输出整理成可迁移规格。
6. 准备最终 checkpoint 的部署与 `held_out_experiment` 配置模板。

## 7. 论文成稿门槛

- R01–R12 每个数字都能回到 immutable Experiment Run/artifact 和分析脚本。
- RGB/state-only/Fixed Dig 的差异只来自预注册的 digging method。
- TADPS 结果同时报告 selector 自身指标和 downstream 指标，不把 planner 碰撞/可达性检查冒充 selector 能力。
- 所有 attempted scoop、失败、超时和人工接管都进入 denominator。
- 结果采用 block-aware uncertainty；不把 frame 或同一料堆相邻 scoop 当独立重复。
- 正文移除与真实 Runtime 不一致的 geometric completion 描述，并根据最终证据收窄 contribution。

## 8. 当前不要做

- 不为填 R03 临时包装一个未经调参的弱 controller，然后宣称 RL 优越。
- 不把现有 104 条训练 Episode 当作 104 个独立土壤 block。
- 不先写“提升百分比”，后补实验。
