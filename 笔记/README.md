## 维护规则

1. 启动入口变化时先改对应仓库 README/Runbook，再更新这里的链接或速查命令。
2. 同一完整命令只在 [相关命令](相关命令.md) 中维护；其他笔记讲目的、顺序和常见错误。
3. 现场结论要注明是“已验证”“待真机验证”还是“历史记录”，不要把推测写成事实。
4. 当前控制网固定使用 PC `192.168.50.1`、Orin `192.168.50.2`；`192.168.31.*` 只可能是 Wi-Fi/历史地址。
