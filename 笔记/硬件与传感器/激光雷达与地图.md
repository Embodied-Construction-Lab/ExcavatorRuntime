# 激光雷达、TF 与 LocalMap

## 数据链

```text
RoboSense UDP 6700/7789/6688
→ rslidar 点云
→ 外参变换到 machine_root_ros
→ LocalMap / OctoMap
→ bucket tip 与占据地图
→ Plan waypoint
```

关键配置：

- `AiryLidar/runtime/config_airy_current.yaml`：雷达型号、IP、端口和 topic；
- `localmap/config/perception.json`：点云、边界和输出；
- `localmap/config/extrinsics_rslidar_to_machine_root_ros.derived.v3.json`：物理重定位后的当前外参，启用前需核对地面、料堆与 bucket tip 对齐；
- `localmap/config/planning.json`：规划 freshness、碰撞和步长。

定位问题时坚持上游到下游：原始点云 → 外参 → 地图 → FK/bucket tip → fresh planning inputs → Plan。

## OctoMap 离线保存

OctoMap 可视化的本质是占据概率树数据，`.bt` 可离线保存后重新加载、换配色和视角用于论文图。保存结果必须有非零节点；`Writing 0 nodes` 只说明服务返回了空地图，不是可用快照。

详细 ROS、OctoMap 和回放命令见 [相关命令](../相关命令.md) 第 6 节。
