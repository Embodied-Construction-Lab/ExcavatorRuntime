# 二、主要流程

## 2.1 STM32 与零命令验收

发动机关闭，Orin/STM32/传感器/相机上电，STM32 复位，双杆居中，deadman 释放。

PC 只读检查 USART2：

```bash
cd /home/zhaoshuai/workspace_uinty/RL_prj/excavator-il
conda activate excavator-il
python scripts/diagnose_stm32_link.py
```

继续的基本条件：

- `passed=true`；
- `parse_failure_count=0`；
- `control_sequence_gap_count=0`；
- 遥测和控制频率均约 20 Hz；
- `max_receive_period_ms <= 80`。

30 秒零命令 soak：

```bash
python scripts/run_zero_command_soak.py
```

预期 `passed=true`，且串口命令、STM32 动作回显和有效专家动作均为零。该诊断 Episode 不进入训练集。

## 2.3 ACT 人工示教采集

### 2.3.1 终端引导采集

```bash
cd /home/zhaoshuai/workspace_uinty/RL_prj/excavator-il
conda activate excavator-il
python scripts/collect_guided_episode.py
```

定位方式：

- `l`：RL Plan DIG → Follow 后采集；
- `y`：手工预定位，完成时双杆回中、释放 deadman，输入 `c`；
- `n` 或回车：直接采集。

正式记录由 deadman 按下开始、释放结束。结果输入：

- `s`：成功；
- `f`：失败；
- `r`：删除本轮并复用同一 Episode ID 重录。

## 2.4 ACT Orin 推理

ACT Runtime 在 Orin 本地读取 STM32 和相机，不需要 PC teleop。日常脚本默认使用
`excavator-act-inference:jp72-pytorch261`，不需要每次手工设置 `ACT_RUNTIME_IMAGE`。

### 2.4.1 Shadow（不写 STM32）

```bash
# Orin
cd /home/jetson16/workspace_excavator/excavator-il
bash scripts/run_act_shadow.sh
```

看到 `ACT hardware ready: mode=shadow` 后运行至少 30 秒，按 `Ctrl+C`，然后：

```bash
bash scripts/inspect_latest_act_runtime_log.sh shadow
```

预期 `passed=true`、`serial_write_count=0`、`nonzero_serial_write_count=0`。

### 2.4.2 Motion（具备 STM32 写权限）

第一次或新 checkpoint 验收时必须先关闭发动机，确保 RL Runtime 和 Collector 均已停止：

```bash
# Orin
cd /home/jetson16/workspace_excavator/excavator-il
bash scripts/run_act_motion.sh
```

终端要求时输入：

```text
ALLOW_ACT_MACHINE_MOTION
```

这是显式本地启动授权，表示允许策略向 STM32 写入杆量。停止后检查：

```bash
bash scripts/inspect_latest_act_runtime_log.sh motion
```

首次发动机开启的非零运动只能在 Shadow 和发动机关闭 Motion 都通过后进行。

## 2.4.3 RL + ACT 混合闭环（Web UI 分段验证）

PC 终端 1 先保持 AiryLidar live Operator 运行：

```bash
cd /home/zhaoshuai/workspace_uinty/RL_prj/AiryLidar

ros2 launch airy_excavator_bringup operator.launch.py \
  profile:=live_commissioning \
  motion_authorization:=ALLOW_LIVE_MACHINE_MOTION \
  orin_host:=192.168.50.2 \
  orin_port:=18083
```

Orin 不要另行启动 RL、Collector 或 ACT。确认非交互 Docker 权限：

```bash
docker info >/dev/null && echo docker-ready
```

PC 终端 2 启动 UI：

```bash
cd /home/zhaoshuai/workspace_uinty/RL_prj/excavator-il
conda activate excavator-il
python scripts/run_collection_ui.py
```

页面选择 DIG 点，点击“开始分段验证”，依次执行 RL 到挖点、ACT 挖掘、RL 到倾倒并固定倾倒、
RL 返回挖点。进入 ACT 段时输入：

```text
ALLOW_HYBRID_MACHINE_MOTION
```

默认 ACT 上限为 130 个 10 Hz live step（约 13 秒），配置在
`excavator-il/config/hybrid_mission.pc.json`。四段分别通过后才点击“自动执行一轮”。
